# Ruble Core

**Ruble Core** is the official wallet software for the Ruble (`RUB`) network.

## Network

- Ticker: `RUB`
- Proof of Work: SHA-256d
- Target block interval: approximately 3 minutes
- Initial block reward: 100 RUB
- Halving interval: 500,000 blocks
- Initial premine: 5,000,000 RUB

Ruble Core is designed to support merged mining in a future network upgrade.
Implementation and deployment details are intentionally not part of the
public release repository.

## Wallet Downloads

Official releases provide:

- Windows x64 Setup
- Windows x64 Portable
- Linux x86_64

Release binaries are distributed through the GitHub Releases section.

Always verify downloaded files using `SHA256SUMS.txt`.

## Security

Back up your wallet before updating wallet software.

Never share:

- private keys
- wallet backups
- recovery material
- passwords

## Project

Official website: https://rublecore.org/

This repository contains public release information and binaries only.
Development source code, infrastructure configuration, pool internals,
deployment procedures, and future network-upgrade implementation details
are maintained separately.
